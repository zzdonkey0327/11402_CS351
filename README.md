## AI-Assisted Development Reflection

Throughout this course, I used AI tools (such as GitHub Copilot and chat-based assistants) as part of my development workflow.  
They helped me generate initial code snippets, suggest test cases, and refine documentation structure when I was unsure how to start.

However, I still needed to carefully verify:

- Whether the proposed algorithms were correct and efficient enough.
- Whether edge cases (invalid input, empty files, boundary values) were fully covered.
- Whether the code style and structure matched the project requirements.

By reviewing and editing AI-generated suggestions instead of accepting them blindly, I learned to treat AI as a **partner** rather than a shortcut.  
This experience improved my ability to read code critically, articulate requirements more clearly, and balance automation with manual design thinking.
